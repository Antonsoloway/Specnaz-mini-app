# 2026-09-05 — v0.6.1 achievement journal integration

## Запрос

Любое фактическое добавление или снятие ачивки администратором должно отображаться в общем журнале админ-режима, а не оставаться отдельным скрытым изменением реестра наград.

## Реализация

- Worker переведён на `entry-v1410.js` / `1.41.0`.
- Награды по-прежнему хранятся в private `achievements.json`; теперь изменение participant awards и соответствующая journal-запись сохраняются одним GitHub contents commit.
- Реестр получил bounded private `journal` (до 500 записей), поэтому история ачивок не зависит от клиентского кэша.
- `/admin-data` объединяет обычный Apps Script journal с achievement journal и отдаёт единый список `adminData.journal.rows`.
- Achievement journal использует уже поддерживаемую UI schema v2: `source=Mini App`, `entity=participant`, actor admin, target participant, committed outcome и явный `diff`.
- Для `МАЯК` журнал показывает `Награда «МАЯК»: Не выдана → Выдана` либо `Выдана → Снята`.
- Поиск/фильтры существующего журнала работают без нового экрана: запись относится к объекту «Участники», ищется по имени администратора, участника и названию награды.
- `requestId` теперь создаётся клиентом для каждой save-операции; повтор того же запроса не создаёт дубль журнала.
- Если состав наград фактически не изменился, новый journal event не создаётся, UI сообщает «Награды без изменений».
- После успешного save journal event добавляется и в текущий in-memory admin snapshot, поэтому он виден при переходе в «Журнал» без ожидания следующей фоновой публикации.
- `project-mayak-v061.js` уже использует `achievements[]` как source of truth для значка и списка участников МАЯКа; legacy ID-list остаётся fallback до получения achievement projection.

## Release

- Frontend marker: `20260905-v061-achievement-journal2`.
- `app.html` → `app-v0601.html` → `app-v0600.html` сохраняют query/hash и принудительно запрашивают новый build.
- Apps Script и структура Google Sheets для этой правки не менялись: achievement events внедряются в общий journal на Worker/private-registry слое.

## Acceptance

1. В админ-режиме открыть участника → «Редактировать» → «Награды».
2. Изменить `МАЯК` и сохранить.
3. Открыть «Журнал» — новая верхняя запись должна содержать администратора, участника и diff награды.
4. Повторно нажать save без изменения checkbox — новая запись не должна появиться.
5. Добавление МАЯКа должно одновременно дать badge и включить участника в «Проекты → МАЯК → Участники проекта»; снятие должно убрать оба проявления.
