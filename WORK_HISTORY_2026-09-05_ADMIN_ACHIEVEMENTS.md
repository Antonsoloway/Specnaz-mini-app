# 2026-09-05 — v0.6.1 admin achievements

## Запрос

В админ-режиме на странице редактирования участника добавить отдельную кнопку «Награды», через которую администратор может выдавать и снимать ачивки. На первом этапе доступна ачивка `МАЯК`; список участников проекта «МАЯК» должен автоматически совпадать с участниками, у которых эта ачивка назначена. Архитектура должна позволять добавлять новые награды позже без переписывания participant editor.

## Реализация

- В private `Antonsoloway/royal-crm-data` создан `achievements.json` — отдельный реестр наград по raw Telegram ID. Реестр заранее заполнен существующими 56 участниками исторического проекта «МАЯК», поэтому текущие ачивки не теряются при переходе на новую систему.
- Добавлен Worker `entry-v1400.js` / `1.40.0` и `worker/wrangler.toml` переключён на него.
- Worker добавляет в защищённый `/snapshot` и `/admin-data` только безопасную проекцию `achievements[]` и `achievementCatalog`; private registry целиком клиенту не отдаётся.
- Добавлен admin-only `POST /admin-achievements`. Права подтверждаются через существующий защищённый `/admin-data`/Telegram admin gate. Запись выполняется только в private data repo через server-side `GITHUB_TOKEN`; токен в браузер не попадает.
- Каталог наград data-driven. Сейчас активен один код `mayak`, в будущем новый тип добавляется в private catalog и автоматически появляется в редакторе.
- Добавлен `admin-achievements-v061.js`: в update-форме существующего участника появляется кнопка `🏅 Награды`. Она раскрывает список наград с checkbox и отдельной кнопкой сохранения. Create-participant flow не менялся.
- Добавлен `project-mayak-v061.js`: badge `МАЯК`, страница участников проекта и счётчик проекта теперь строятся по `participant.achievements`, а не по жёстко вшитому списку. До появления Worker projection сохранён legacy fallback на прежние 56 ID.
- После успешного admin save текущий клиент немедленно обновляет local public/admin participant record и вызывает `RoyalMayak.refresh()`, поэтому выдача/снятие `МАЯК` сразу отражается в ачивке и списке проекта без перезагрузки страницы.
- Runtime подключён через marker `20260905-v061-admin-achievements1`; rollback v0.5.59 продолжает использовать старый `project-mayak-v0536.js` и не изменён.

## Хранилища и границы

- Google Sheets и Apps Script для этой функции не менялись: награды — самостоятельный расширяемый private registry, а не новое системное поле participant sheet.
- Существующие participant/team writes, admin journal, роли, memberships, музыка, проекты и Worker routes не заменены.
- Public Mini App видит только список кодов наград конкретного участника и безопасный каталог названий.

## Device acceptance

1. Полностью закрыть Mini App и открыть заново через Telegram.
2. Админ → участник → `Редактировать участника` → `🏅 Награды`.
3. Поставить `МАЯК` → `Сохранить награды`: на карточке должна появиться ачивка и участник должен появиться в `Проекты → МАЯК → Участники проекта`.
4. Снять `МАЯК` и сохранить: ачивка и строка в списке проекта должны исчезнуть.
5. Обычное сохранение имени/memberships должно продолжать работать независимо от отдельного сохранения наград.
