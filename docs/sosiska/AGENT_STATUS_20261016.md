# Уровень и самодиагностика на карточке агента

Требование владельца: на главной кнопке Сосиски показывать текущий уровень аккаунта и онлайн/офлайн. Позже появятся другие агенты, включая RK; сейчас работает только Сосиска/RM.

Реализовано: общий `data-agent-id`, клиентский модуль `agent-status-v061.js/css`, безопасный серверный каталог и `operation:status` за существующей админской авторизацией. Сервер вызывает health и отдельный `diagnostics` облачного агента. Зелёный онлайн требует свежего успешного игрового Ping и валидных уровня/максимума; health с настроенной сессией этого не доказывает. Диагностика использует только read-only Ping, не повышает уровень, не создаёт снимки, не меняет расписание.

Игровая диагностика кэшируется в DO до60 секунд. UI обновляет карточки раз в минуту только на видимом главном экране. Онлайн автоматически теряет актуальность через90 секунд. Занятая очередь — «Занят», подтверждённый отказ игрового соединения — «Офлайн», ошибка связи браузера с API — «Нет связи». Последний известный уровень сохраняется с пометкой в подсказке; зелёный снимается. При смене сессии/отказе доступа данные и поздние ответы очищаются. Локальное долговременное хранение статуса и game credentials в браузере не используются.

Общие поля `id/name/game/status/level/maxLevel/levelVerified/checkedAt/lastOnlineAt` позволяют добавить другой агент отдельным серверным probe и карточкой. Пустых RK-кнопок и произвольного upstream URL из браузера нет.
