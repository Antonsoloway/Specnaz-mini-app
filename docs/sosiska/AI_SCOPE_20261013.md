# ИИ-анализ в контексте команды и сравнения

Module 0.5.2; release `20261013-v061-sosiska-scope1`.

По требованию владельца ИИ запускается внутри открытой команды и читает только её полную историю. В режиме сравнения анализируются только выбранные 2–5 команд. Глобальная кнопка всех отслеживаемых команд удалена; API отклоняет запуск без явной команды или набора. Автоматического запуска при открытии нет.

Статус и отчёт привязаны к точному набору ID. Смена карточки/набора очищает предыдущий отчёт и читает сохранённую задачу соответствующего контекста. Проверяется совпадение scope и ID ответа. Запоздалый poll предыдущей задачи игнорируется. При возврате сохраняется серверный отчёт данного контекста. Старые задачи до появления scope-индекса не подмешиваются к новым карточкам. Уже выполняющаяся задача продолжает работать; запуск другого контекста сообщает, что предыдущая задача ещё выполняется.

Полная история, графики, снимки, расписание, ключи и игровые сессии сохранены. Финальный запрос одной команды формирует итог только этой команды; выбранного набора — сравнение данного набора.
