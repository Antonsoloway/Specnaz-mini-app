## Требования владельца

Сосиска — отдельный админский модуль. Не сломать действующее приложение. Существующие страницы, CRM, админка, музыка, роли, награды, Telegram-авторизация и Apps Script должны сохранить поведение.

Поиск Royal Match гибридный: прямой поиск и рейтинги, с визуальными русскими/латинскими вариантами. При одинаковых названиях показать описание и лидера. Максимум фактически доступных серверных полей команды/состава, роли, уровни, короны, помощь, ID эмблемы. Не выдавать Level+Crown/Score за доказанные очки битв.

Наблюдение по заданному администратором расписанию, неизменяемые снимки, сравнение игроков по UserId, входы/выходы/смены ролей. Статус выхода нейтральный, сервер не доказал причину. ИИ-анализ **всей истории всех отслеживаемых команд**, включая ранние снимки и все интервалы; не ограничивать двумя снимками. Точный числовой ряд доступен отдельно от резюме ИИ.

Сервисный игровой аккаунт не играет и не входит в лигу. Изменение уровня отложено. Не включать watch на примерах автоматически. Не удалять историю, не менять ботов. R2/Vectorize в этой задаче не вводились. Секреты только на сервере.

Владелец сообщил один Cloudflare аккаунт, а Google Apps Script может быть на двух Google аккаунтах. Не утверждать наличие второго пользовательского Cloudflare логина на основании расхождения OAuth ресурсов.
