# Дополнительные фильтры поиска Сосиски — 12 октября 2026

В поиске по названию теперь можно совместно задать: командные очки от (включительно), часть/полный ник лидера без учёта регистра, количество участников от/до (0–50), уровень входа от/до, короны входа от/до и открытый/закрытый тип команды. Очки вычисляются из актуального состава как сумма Level+Crown; не используются неизвестное серверное поле Score, очки события или рейтинговый срез.

Фильтры уточняют весь список кандидатов, а не только первую страницу. Начальный поиск по-прежнему подгружает 4 описания. Применение активных фильтров последовательно получает недостающие подробности всех кандидатов через существующий защищённый team API; кэш уже загруженных подробностей сохраняется до нового поиска. Счётчик отражает ход загрузки. Остановить загрузку можно кнопкой; переход на другую страницу прекращает следующие запросы и игнорирует поздний ответ. Watches/captures не создаются.

При ошибке подробности кандидата не выдаются за проверенные: показаны число непроверенных команд и инструкция повторно применить фильтры. Следующий запуск повторяет только отсутствующие подробности. Ошибки поиска источников также остаются видны после фильтрации. Кнопка сброса возвращает исходный список; пагинация работает по отфильтрованному списку.

В карточках результатов показываются командные очки, лидер, участники, входной уровень/короны, тип команды и ID/номер эмблемы. Реальная картинка эмблемы не добавлена: текущий контракт передаёт только числовой Logo; соответствие арту не восстановлено. HTML игровых значений экранируется.

Лимит: фильтры не возвращают команды, исключённые игровым сервером из search/leaderboard, и не снимают ограничение результатов игрового поиска. При большом числе кандидатов первая загрузка подробностей занимает время; запросы сериализованы и отменяемы на уровне очереди UI.
